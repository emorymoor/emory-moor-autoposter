Information We Access The application may access information provided through the Pinterest API, including: * Pinterest account information necessary for authentication; * Pinterest boards; * Pins and content associated with the connected account; * permissions granted by the user through Pinterest OAuth. The application does not request or store Pinterest passwords. ## 3. How Information Is Used Information accessed through Pinterest is used only to provide the application's functionality, including: * selecting Pinterest boards; * creating and publishing Pins; * scheduling book-related content; * managing content created through the application. Pinterest data is not sold or shared with advertisers or unrelated third parties. ## 4. Authentication The application uses Pinterest's official OAuth authentication process. Access tokens are used only to communicate with the Pinterest API and provide requested application functionality. ## 5. Data Storage The application stores only the information necessary to provide its functionality.
